# SingleSelect 单选

轻量的单选下拉组件。点击触发器展开选项列表，选中后通过 `change` 事件回调并自动收起；点击组件外部区域也会自动收起。

## Props

| 参数           | 说明                                   | 类型                | 默认值    |
| -------------- | -------------------------------------- | ------------------- | --------- |
| `items`        | 选项数据数组                           | `Array<any>`        | `[]`      |
| `duration`     | 展开 / 收起过渡动画时长（ms）          | `number`            | `300`     |
| `animation`    | 过渡动画类型                           | `"fade" \| "slide"` | `"slide"` |
| `maxHeight`    | 选项列表容器最大高度（px），超出可滚动 | `number`            | `260`     |
| `bg`           | 选项列表容器背景色（预留）             | `string`            | —         |
| `offsetY`      | 选项列表纵向偏移（预留）               | `number`            | —         |
| `offsetX`      | 选项列表横向偏移（预留）               | `number`            | —         |
| `optionsClass` | 选项列表容器自定义类名（预留）         | `string`            | `""`      |

## 事件

| 事件名   | 说明             | 回调参数                              |
| -------- | ---------------- | ------------------------------------- |
| `change` | 选中某一项时触发 | `(value: any, index: number) => void` |

## 插槽

| 插槽名    | 子作用域          | 说明                                |
| --------- | ----------------- | ----------------------------------- |
| `default` | —                 | 触发器显示内容，点击切换展开 / 收起 |
| `option`  | `{ item, index }` | 自定义选项渲染，`item` 为对应数据项 |

## 说明

- 组件内部维护展开状态 `visible`（初始为展开），点击触发器切换，点击外部或选中选项后收起。
- 选中值不由组件托管，需通过 `change` 事件自行保存，组件不提供 `v-model`。
- 通过 `option` 插槽可完全自定义每个选项的渲染内容。
